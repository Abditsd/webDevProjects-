# KingsSupport – Kings Support Website

A React + React Router DOM website for Kings Support.

## 📁 Project Structure

```
kingswell-care/
├── public/
│   └── index.html
├── src/
│   ├── components/
│   │   ├── Header.jsx
│   │   ├── Header.css
│   │   └── Footer.jsx
│   ├── pages/
│   │   ├── Home.jsx
│   │   ├── About.jsx
│   │   ├── Services.jsx
│   │   ├── Safeguarding.jsx
│   │   └── Contact.jsx
│   ├── styles/
│   │   └── global.css
│   ├── App.jsx
│   └── index.js
└── package.json
```

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start the development server
```bash
npm start
```

The site will open at **http://localhost:3000**

### 3. Build for production
```bash
npm run build
```
